# Supabase Backend

أنشئ مشروع Supabase ثم نفّذ ملفات `migrations` بالترتيب عبر Supabase CLI أو SQL Editor.

قبل إدخال بيانات حقيقية:
- راجع سياسات RLS واختبرها لكل دور.
- لا تستخدم Service Role Key في تطبيق الهاتف أو المتصفح.
- خزّن الملفات الحساسة في buckets خاصة مع سياسات وصول مناسبة.
- فعّل النسخ الاحتياطي وفق خطة الاستضافة.
