# نظام مدرسة الجوادين الإلكتروني

هيكل أولي لمشروع متعدد التطبيقات:
- `mobile/`: تطبيق Flutter لأجهزة Android.
- `admin/`: لوحة إدارة Next.js.
- `backend/`: مخططات Supabase وملفات SQL.
- `.github/workflows/`: فحوصات وبناء Android.

> **تنبيه:** هذا المستودع هو نقطة انطلاق منظمة فقط. لا يحتوي بعد على ربط Supabase/Firebase حقيقي، ولا يجوز استخدامه في الإنتاج قبل تنفيذ المراحل الأمنية والوظيفية والاختبارات.

## المتطلبات
- Flutter SDK مستقر متوافق مع Dart المحدد في `mobile/pubspec.yaml`.
- Node.js LTS وnpm.
- حساب Supabase ومشروع Firebase عند مرحلة الربط.

## التشغيل المحلي
### تطبيق الهاتف
```bash
cd mobile
flutter pub get
flutter run
```

### لوحة الإدارة
```bash
cd admin
npm install
npm run dev
```

## الإعداد
انسخ `admin/.env.example` إلى `admin/.env.local` وأدخل القيم من لوحة Supabase. لا تضع مفاتيح سرية في تطبيق الهاتف أو Git.

## مراحل التنفيذ
1. تجهيز الهيكل (هذه النسخة).
2. تصميم مخطط PostgreSQL وسياسات RLS واختبارها.
3. المصادقة وربط الأدوار.
4. بناء شاشات الهاتف واللوحة وربطهما.
5. تنفيذ الإشعارات والملفات.
6. الاختبارات والتدقيق الأمني.
7. إعداد التوقيع وإصدار APK.

راجع `docs/` قبل النشر.
